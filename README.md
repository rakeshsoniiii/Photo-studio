# Photo-studio

## Studio Erato Films — Destination Weddings & Bespoke Films

A luxury destination wedding photography and bespoke cinematography website inspired by high-end editorial publications and [Piixonova](https://piixonova.com/).

### ✨ Key Features
- **Editorial Hero Section**: 3 continuously moving vertical photo columns with smooth infinite looping marquee animations showcasing curated high-resolution wedding photography.
- **Piixonova-inspired Design**: Luxury serif typography, rose-pink script accent, glowing pill CTA with animated aura and sparkles, social proof ratings, and 4 frosted feature cards.
- **Bottom Stats Capsule**: 3-part glassmorphism pill highlighting wedding milestones and couple testimonials.
- **Autoplaying Video Reels**: Portrait 9:16 reels in an infinite seamless loop with tap-for-sound audio toggle.
- **Sticky Fullscreen Photography Exhibition**: Pinned photography showcase sliding smoothly right-to-left on scroll with HUD counters and progress indicator.
- **Cinematic Film Showcase**: Curated video cinema teasers with interactive modal playback.
- **Universal Custom Cursor**: Difference blend-mode precision cursor with interactive hover expansion.
- **Mobile Responsive**: Custom touch-friendly layouts optimized for handheld viewports.

### 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router with Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Animations**: GSAP, ScrollTrigger, Lenis Smooth Scroll
- **Icons**: Lucide React

### 🚀 Getting Started

```bash
cd studioeratofilms
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.
